# Лабиринт сокровищ

**Лабиринт сокровищ** — это консольная текстовая игра, где вы исследуете комнаты, решаете загадки, собираете предметы и пытаетесь открыть сундук с сокровищем.

Игроку предстоит пройти через опасные ловушки, библиотеку с древними загадками и оружейную комнату, чтобы в конце найти и открыть сундук в комнате сокровищ.

---

## Установка

Установить зависимости можно двумя способами:

### С помощью poetry:
```bash
poetry install
```

### С помощью make:
```bash
make install
```
## Запуск игры

### С помощью poetry:
```bash
poetry run project
```

### С помощью make:
```bash
make project
```

### Усправление героем можно узнать по следующей команде:
```bash
help
```
